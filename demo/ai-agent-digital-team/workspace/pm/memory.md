# 记忆

## 高频失败模式（来自复盘 2026-05-07）

### 模式 1：验收标准缺少异常路径
- **现象**：文档只写「用户登录成功跳转首页」，未写「密码错误时提示『密码不正确，请重试』」
- **触发任务**：t001、t003
- **预防**：撰写每条验收标准后，立即追问「如果用户输入错误/网络失败，会发生什么？」

### 模式 2：平台约束（移动端/桌面端）在撰写阶段被遗忘
- **现象**：需求写「移动端优先」，文档却以桌面端视角描述交互
- **触发任务**：t001、t006
- **预防**：步骤 3.5 提取的平台约束必须写入文档「关键约束」小节，不得仅在脑中记忆
