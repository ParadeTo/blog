# 产品规格文档

> 版本：v1.0 | 日期：2026-05-07 | 作者：PM

---

## 项目背景

用户在日常工作中依赖便利贴和备忘录管理待办事项，导致任务容易遗忘、优先级混乱。本项目旨在开发一款**命令行版智能待办事项助手**，帮助个人用户快速录入、管理和追踪待办任务，解决"不知道先做什么"的核心痛点。技术栈为 Node.js，本地文件存储，单人开发，预计 2 周交付。

---

## 目标用户

| 维度 | 描述 |
|------|------|
| **主要用户** | 习惯使用命令行的个人开发者 / 技术工作者 |
| **核心场景** | 工作中随时产生新任务，需要快速记录并在合适时机回顾执行 |
| **核心诉求** | 录入快（30 秒内完成）、列表清晰（按优先级排序）、不遗漏（临近截止有提醒） |

---

## 核心功能

| 功能模块 | 功能描述 | 优先级 |
|---------|---------|--------|
| 添加任务 | 用自然语言描述任务，系统自动提取标题和截止时间；解析失败时允许无截止时间任务存在（兜底方案） | P0 |
| 查看列表 | 按优先级和截止时间排序展示所有未完成任务，支持至少 100 条任务不卡顿 | P0 |
| 标记完成 | 将指定任务标记为已完成状态，从未完成列表中移除 | P0 |
| 智能提醒 | 每次运行命令时检查临近截止任务并在终端提示（无需后台常驻进程） | P1 |
| 优先级设定 | 用户手动指定优先级（high / medium / low），系统按此排序 | P1 |

> **待澄清项说明（已采用默认方案）：**
> - 自然语言解析失败时：允许无截止时间的任务存在，提示用户可手动补充
> - 智能提醒触发机制：每次运行命令时检查，无需后台进程
> - 优先级设定方式：用户手动指定（high / medium / low）
> - "并发任务"含义：同时存在至少 100 条未完成任务，系统响应不卡顿

## 用户故事

**US-01 添加任务（P0）**
> 作为命令行用户，我希望用自然语言描述一个任务（如 `add "明天下午3点前提交报告"`），系统自动提取标题和截止时间，以便我在 30 秒内完成录入而无需手动填写结构化字段。

**US-02 解析失败兜底（P0）**
> 作为命令行用户，当系统无法从描述中提取截止时间时，我希望系统提示我"未识别到截止时间，任务已保存（无截止时间）"，以便任务不丢失，我可以后续手动补充。

**US-03 查看任务列表（P0）**
> 作为命令行用户，我希望运行 `list` 命令后看到按优先级和截止时间排序的未完成任务列表，以便我清楚知道当前最紧急的事项是什么。

**US-04 标记任务完成（P0）**
> 作为命令行用户，我希望通过任务 ID 或序号将任务标记为完成（如 `done 3`），以便已完成的任务不再出现在列表中干扰我的注意力。

**US-05 智能提醒（P1）**
> 作为命令行用户，每次我运行任意命令时，我希望系统自动检查并在终端顶部提示"⚠️ 以下任务即将截止"，以便我不会因为忘记查看而错过 deadline。

**US-06 手动设置优先级（P1）**
> 作为命令行用户，我希望在添加任务时或事后通过命令指定优先级（high / medium / low），以便系统能按我的判断而非仅截止时间来排序任务。

## 验收标准

### AC-01 添加任务
- [ ] 执行 `add "明天下午3点前提交报告"` 后，任务被保存，标题和截止时间被正确提取
- [ ] 从输入到保存完成，全程不超过 30 秒（含命令执行时间）
- [ ] 任务持久化到本地文件，重启命令行后仍可查看

### AC-02 解析失败兜底
- [ ] 当描述中无法识别截止时间时，任务仍被保存（截止时间字段为空）
- [ ] 终端输出提示信息："未识别到截止时间，任务已保存（无截止时间）"
- [ ] 无截止时间的任务在列表中排在有截止时间任务之后

### AC-03 查看任务列表
- [ ] `list` 命令输出所有未完成任务，按优先级（high > medium > low）排序，同优先级按截止时间升序
- [ ] 列表中存在 100 条未完成任务时，命令响应时间 < 2 秒
- [ ] 已完成任务不出现在列表中

### AC-04 标记完成
- [ ] `done <id>` 执行后，对应任务状态变为已完成
- [ ] 再次执行 `list` 时，该任务不再出现
- [ ] 对不存在的 ID 执行 `done` 时，输出友好错误提示

### AC-05 智能提醒
- [ ] 运行任意命令时，若存在 24 小时内截止的未完成任务，终端输出提醒列表
- [ ] 无临近截止任务时，不输出提醒（不干扰正常输出）

### AC-06 优先级设定
- [ ] 添加任务时可通过参数指定优先级，如 `add "任务描述" --priority high`
- [ ] 未指定优先级时默认为 `medium`
- [ ] `list` 输出中优先级字段可见（如 `[HIGH]`、`[MED]`、`[LOW]`）

## 非功能性需求

| 维度 | 要求 |
|------|------|
| 性能 | 100 条任务时所有命令响应 < 2 秒 |
| 存储 | 本地文件存储（JSON 或纯文本），不依赖外部数据库 |
| 运行环境 | Node.js，命令行界面，无需 GUI |
| 可靠性 | 任务数据持久化，进程退出后不丢失 |

---

## 范围外（Out of Scope）

本期明确不做以下内容，避免需求蔓延：

- **图形界面（GUI）**：本产品定位为纯命令行工具
- **外部数据库集成**：仅使用本地文件存储
- **多人协作 / 团队共享**：本期仅支持单用户本地使用
- **移动端 / Web 端支持**：不在本期范围内
- **后台常驻进程 / cron 定时推送**：提醒机制仅在命令执行时触发
