# Agent Security Guardrails Demo

JavaScript demo for runtime Agent security guardrails:

- `SandboxGuard`
- `PermissionGate`
- `SecureToolWrapper`
- `SecurityAuditLogger`

## Setup

```bash
npm install
```

## Run

```bash
npm start
npm run attack:privilege
npm run attack:inject
npm run attack:api-leak
```

## Test

```bash
npm test
```
